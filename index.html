New LMS 교안 준비기

노트북(.ipynb)을 New LMS 업로드 규격에 맞는 파일로 만들어 드려요.

  1. 1
    노트북 올리기
    원본 파일은 바뀌지 않아요.
    .ipynb 파일을 끌어다 놓거나 클릭해서 선택하세요
  2. 2
    노드 정보
    섹션 제목과 모든 셀에 함께 저장되는 값이에요.
  3. 3
    섹션 나누기
    섹션 하나가 LMS 스텝 하나가 돼요. 내용 수정은 Jupyter 에서 하고, 여기서는 경계와 제목만 정리해요.
  4. 4
    어드민 입력값
    노트북에는 들어가지 않아요. 답안 파일로 받아서 어드민에 직접 입력하세요.

    Storage path 는 {코스코드}-{순서}-{추가정보}/data 형식이에요. 노드 이름과 다를 수 있으니 실제 값을 꼭 확인하세요. (예: E-7-L 노드가 DS-ML-10/data 사용)
    node slug 는 노드마다 하나씩 지어요. 형식: {파일이름}_newlms_{날짜} — 예: 1-1-1_newlms_250331

  5. 5
    변환본 받기
    변환 후 판정

    자동 처리: 실행 결과 비우기 · 코드 셀 정보 채우기 · step_id 제거 · 섹션 번호 재정렬 · 커널 정보 고정
    업로드는 스텝이 없는 노드 버전에서 하세요.
